# Aile Uygulamaları

Bu evde yapılan iPhone uygulamalarının AltStore / SideStore kaynağı.

Kaynak adresi:

```
https://raw.githubusercontent.com/datcal/sideload/main/apps.json
```

Burada kaynak kodu yok — yalnızca uygulama listesi, simgeler ve
Releases altındaki kurulum dosyaları.

Uygulamalar **imzasız** yayınlanır: kuran kişi kendi ücretsiz Apple
kimliğiyle imzalar. Kurulum anlatımı uygulamayı yapan deponun
`docs/sideload.md` dosyasında.
